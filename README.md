VIBE-CODE-AGI

A modular, recursive cognitive architecture prototype in Python, inspired by speculative AGI research. This experimental project explores a layered cognitive stack designed to simulate perception, reasoning, memory, adaptation, and self-reflection in a structured, transparent way.

Vision to build a system for AGI ideas, not a full artificial general intelligence initially, but a modular framework where layers can be tested, swapped, and evolved independently. Think of it as a "mind in code": inputs flow upward through perception → reasoning → memory → adaptation, with recursive loops for self-improvement and reflection. 

Core Concepts 

Perception — Multimodal input processing (text, images, code, audio placeholders)
Embedding & Context — Vector representations and short-term memory
Reasoning Core — Forward inference and decision making
Long-Term Memory — Vector database for experience storage and retrieval
Reflection Layer — Meta-analysis of past actions and outcomes
Vibe Adapter — Self-modification based on feedback or goals
Action & Output — Generate responses, code, or external calls

Recursive loops allow the system to "think about its own thinking" and gradually adapt. Tech StackPython — Core implementation
PyTorch — Neural components and potential model integration
FAISS — Efficient vector memory storage and similarity search
Transformers / Sentence-Transformers — Embedding models (local or API)
LangChain / LlamaIndex concepts — Inspiration for memory and retrieval
